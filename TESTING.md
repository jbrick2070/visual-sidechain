Changes verified by this audit:

- One coherent fader snapshot per render replaces repeated mutex acquisitions. Reactivity scales only the CPU scalar uniforms it uses; GPU texture helpers handle texture scaling.
- Both FFTs use the same audio snapshot. At default sizes, ring-locked copies fall from 6,144 to 4,096 samples per tick (33% fewer), with one ring lock instead of two. Audio callbacks allocate no memory; plans/textures are reused.
- Feedback targets allocate lazily, release on shader switches, and reset on size/color-space changes. Four retained 4K RGBA targets previously represented about 126.6 MiB of raw texture storage. Both render paths now negotiate OBS color formats.
- Custom-Hz Flux now retains the current positive spectral delta after analyzer updates. Frequency bounds, delayed startup DC removal, callback mute preference, numeric overflow, parser metadata, event coalescing, duplicate slot ownership, and default range reload/retarget behavior have regression coverage.
- Named-source taps reconnect after source destruction. Modulator target replacement invalidates epsilon gates and restores/forgets the removed filter's baseline without per-frame property discovery.
- Test harnesses never kill OBS or close it automatically. Close OBS manually after a run to inspect the shutdown leak count.

Limits: this is a short synthetic SDR test on one machine, not a worst-case animated/audio-driven 4K benchmark or a long-session soak. HDR format handling was code-reviewed and compiled but not visually verified with HDR media. Separate Audio Modulator instances can still compete if configured for the same target setting; integer dropdowns with sparse option values are treated as contiguous ranges. Within one modulator, the first enabled slot owns a duplicate target.
